# Dataset Setup

Use the Kaggle `creditcard.csv` dataset for this project.

## Option 1: Keep the zip file

Place `creditcard.csv.zip` inside this `data/` folder.

## Option 2: Extract the CSV

Place `creditcard.csv` inside this `data/` folder.

## Notes

- The training script supports both `.csv` and `.zip`
- The dataset is intentionally excluded from git
- You can also pass a custom path with `--input`
